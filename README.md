# UTS Pemrograman Berorientasi Objek

## Deskripsi
Program Python untuk mengolah data karyawan dan data sensor
menggunakan konsep Object-Oriented Programming (OOP).

## Konsep OOP
- Rule atau aturan bisnis
- Inheritance
- Polymorphism
- Method Override
- Abstract Class

## Pengolahan Data
1. Membaca data karyawan dari employee.json.
2. Menghitung bonus dan total gaji karyawan.
3. Membaca data suhu sensor dari sensor_logs.json.
4. Mengklasifikasikan sensor menjadi DANGER, WARNING, dan NORMAL.
5. Menyimpan hasil pengolahan dalam file JSON.

## Cara Menjalankan
Pastikan Python sudah terpasang, kemudian jalankan:

python main.py

## Struktur File
- main.py
- data/employee.json
- data/sensor_logs.json
- data/employee_results.json
- data/sensor_results.json
